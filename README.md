# La Marea

Demo landing page for an invented Pacific coast restaurant in Cali, Colombia. The page is a 1970s salsa record: the plate is the disc and the menu plays as Side A / Side B. Built with Vue 3, TypeScript, Vite and Tailwind CSS v4.

The restaurant, its menu, prices and schedules are made up. The booking form sends nothing.

```bash
npm install
npm run dev
```

`npm run build` type-checks and builds. Photos from Unsplash, see [public/photos/CREDITS.md](public/photos/CREDITS.md). Fonts (Bagel Fat One, Barlow Semi Condensed) are self-hosted through Fontsource.
